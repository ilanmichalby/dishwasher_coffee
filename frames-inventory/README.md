# מלאי מסגרות

טופס מותאם לנייד לעדכון שדה הכמות בשורות קיימות בטבלת Airtable.

## הגדרה
1. העתק את `.env.example` לקובץ `.env.local` ומלא את הערכים.
2. `npm install && npm run dev`

## פריסה ל-Vercel
ייבא את ה-repo, הגדר את Root Directory כ-`frames-inventory`, והוסף את משתני הסביבה מתוך `.env.example`.
הטוקן נשאר בשרת בלבד ולא נשלח לדפדפן.
